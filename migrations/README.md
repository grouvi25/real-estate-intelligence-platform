# Нумерация миграций

## Диапазоны

- `001-009`: базовая MVP-схема и ранние дополнения.
- `010-039`: намеренно не использовались. Не заполнять задним числом.
- `040-054`: Signal Bus и последующие совместимые изменения текущей схемы.
- `055-059`: ближайшие исправления текущей схемы.
- `060+`: зарезервировано для будущих SaaS-функций.

Разрыв `010-039` не означает потерянные файлы. Signal Bus проектировался отдельным блоком и получил диапазон `040+`, чтобы визуально не смешиваться с MVP.

## Новая миграция

Диапазон `055-059` занят полностью (последняя — `059_topnlab_lead_sync.sql`).
Следующая миграция — `060`, первая из диапазона SaaS-функций:

```bash
touch migrations/060_your_feature_name.sql
```

Не переиспользуйте существующий номер и не создавайте файлы в `010-039`.

## Применение

SQL-миграции применяются при старте через `run_migrations`. Alembic хранит baseline для новых окружений. Автоматического downgrade нет: перед изменением production-схемы делайте резервную копию.
