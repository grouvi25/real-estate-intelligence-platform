## Вывод

Конвейер собран и проверен на каждом стыке на живых данных: вход в Telegram →
поиск чатов → оценка источника по его сообщениям → сбор → фильтр → AI-скоринг →
лид → подбор → документ. Фоновые задачи не падают, ежедневный отчёт доставляется,
50 RPS держатся с двухпорядковым запасом, деплой автоматический.

Система нашла первого настоящего покупателя без участия человека: чат обнаружил
поиск, сообщение прочитал коллектор, отсеял фильтр, оценил AI — «Запрос: квартира
в г.Геленджик бюджет до 5 млн (наличка)», 80 баллов, горячий.

Что мешает работать по-настоящему — не код, а данные и доступы: в базе два
тестовых объекта вместо каталога агентства, аккаунт-коллектор совпадает с
админским, ключи Yandex Cloud и MAX — заглушки. Каждый из этих пунктов закрывается
загрузкой или ключом, без доработки.

Главный урок, ради которого написан этот документ: **из двадцати дефектов выше ни
один не был виден при чтении кода.** Модули существовали, тесты проходили, CI был
зелёный — и система не работала. Находились они только на сквозных прогонах с
настоящими данными, поэтому проверки, добавленные в CI (достижимость экранов и
эндпоинтов, санитайзеры вокруг ответов AI, тесты на живых текстах из чатов),
важнее любой галочки в чек-листе.
