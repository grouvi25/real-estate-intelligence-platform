## Что было сломано в работающей системе

Каждый пункт нашёлся при запуске, а не при чтении кода.

| # | Симптом | Корень |
|---|---|---|
| 1 | ~870 ошибок в сутки, 2 из 3 фоновых задач падали, отчёт руководителю не уходил | gevent-пул + `asyncio.run()` на каждую задачу; вдобавок asyncpg-соединения переживали свой event loop |
| 2 | CI красный на нетронутом коде | `ruff` не запинен, версия 0.16 расширила набор правил по умолчанию |
| 3 | Система не увидела бы ни одного сообщения | AI сгенерировал ключевики уровня региона, а `quick_filter` требует совпадения по названию города |
| 4 | Продавцы шли как покупатели | `quick_filter` не читал `negative_keywords` гео (дефект ТЗ 16.1) |
| 5 | Вход в Telegram невозможен | провайдер режет 443/80 к DC2/DC4; порт 5222 открыт |
| 6 | Поиск нашёл 6 чатов, сбор дал 0 сигналов | discovery пишет числовой id чата, коллектор ожидал username |
| 7 | 25 собранных «сигналов», покупателей 0 | реклама мебели проходила: «Геленджик**ский**» + основа «дома» внутри «**дома**шняя»; намерение купить не требовалось |
| 8 | Чат аренды получил 80 баллов и ушёл в работу | оценка источников ранжировала только по географии (дефект ТЗ 27.1) |
| 9 | Единственный профильный чат отбракован с 0 баллов | оценка шла вслепую: поиск не отдавал примеры сообщений |
| 10 | Рекламный анонс оценён как «инвестор, 60, тёплый» | промпт скоринга оценивал тему текста, а не намерение автора (дефект ТЗ 27.1) |
| 11 | Токен бота писался в логи целиком | httpx кладёт URL в текст ошибки, а токен лежит в URL |

Функции, до которых нельзя было добраться: задачи создавались, но их негде было
увидеть; источник нельзя было остановить иначе как SQL-запросом; `partners/accept`
упоминался в ответе API, но не существовал; детальные экраны грузили список из
200 записей и показывали «не найдено» для всего, что за лимитом.

## Вывод

Конвейер собран и проверен на каждом стыке: вход в Telegram → поиск чатов →
оценка по содержимому → сбор сообщений → фильтр → AI-скоринг → лид. Фоновые
задачи не падают, ежедневный отчёт доставляется, нагрузка 50 RPS держится с
двухпорядковым запасом.

Чего система пока не делает — не находит живых покупателей: в Telegram по
Геленджику их почти нет там, где умеет искать встроенный поиск. Это следующая
задача, и она продуктовая: расширять географию, добавлять источники вручную через
новый экран, подключать VK и классифайды.
